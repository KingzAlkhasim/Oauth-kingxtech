# Getting started
> Create your account, make your first project and put it online in a few minutes.

KingxTech is a place to build, host and ship software. You can write code yourself, or ask K-XpertAI, the built-in AI assistant, to build it for you. Everything works from a phone.

{{video: PASTE_YOUTUBE_LINK_HERE}}

## 1. Create your account

Open the sign-up page and register with your email or with Google or GitHub. You agree to the [Terms of Service](/terms) when you sign up. You can add two-factor sign-in later under Account → Security.

## 2. Create your first project

Go to **Projects** and press **New project**. Give it a name and choose **Start from**:

- **Blank** to start from nothing and let K-XpertAI build it.
- **Landing page, Portfolio, Link page, Shop catalog or Dashboard** to start from a ready-made page you can edit.

After you create it, the project opens in the workspace.

## 3. Edit your files

The workspace has a file list, an editor and a preview. Change the text, colors and links to make it yours. Or open K-XpertAI (the sparkle button) and describe what you want.

## 4. Publish

Press **Publish**. In a short time your site is live at an address like `site.kingxtech.name.ng/your-project/`. Press **Copy link** to share it.
