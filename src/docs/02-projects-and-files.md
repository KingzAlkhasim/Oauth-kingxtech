# Projects and files
> Create projects, add files and images, and import existing work.

## Create a project

On **Projects**, press **New project**. Pick a starter template or Blank. You can rename a project or change its description later with the pencil icon.

## Files and folders

Inside a project, use the icons above the file list to create a new file or folder, upload files, import from GitHub, or import a local folder. Tap a file to open it. Changes save as you work.

## Uploading images and other files

You can upload PNG, JPG, GIF, WebP, AVIF, ICO, SVG, fonts (WOFF, WOFF2, TTF, OTF) and PDF files. Each file can be up to 5 MB. Videos are not supported yet.

Images and fonts are stored in a way that makes them about a third larger than their size on your device. Your [storage limit](/docs/plans-and-limits) counts that stored size.

## Import from GitHub or a folder

- **GitHub:** enter `owner/repo` and the branch. KingxTech brings in the files from that branch. Large repositories can take a minute.
- **Local folder:** choose a folder on your device. Up to 300 files are imported. Files named `.env`, and the `node_modules` and `.git` folders, are skipped on purpose so secrets and bulky files are not uploaded.

A progress bar shows which file is being imported. When it finishes you see how many files were imported and which were skipped.

## Undo and restore

K-XpertAI shows its changes so you can accept or reject them. Each changed file can also be undone. For whole-project safety, see [Restore points](/docs/publishing#restore-points).
